# 描画改善 (小粒4件) 設計書

- 日付: 2026-07-15
- 対象: TODO.md の項目1・3・4・5
- 関連: 項目2 (Edit の入力要約表示) は設計論点が大きいため本設計の対象外とし、別途ブレストのうえ独立した spec を作成する

## 背景

実際の開発セッションを cctx で描画した際のフィードバック (TODO.md) のうち、設計論点の少ない4件をまとめて対応する。いずれも「イベント列またはツール Summary を parse 側で正しくし、md / html 両テンプレートに同時に効かせる」方針で統一する。

## 項目1 — テキストなしアシスタントターンの見出し常時表示

### 問題

前置きテキストなしでツールだけを呼んだアシスタントターンでは `assistant_message` イベントが生成されず、`tool_call` が直前のユーザー発言にぶら下がって見える。発言の帰属が壊れる。

### 設計

- parse: テキストが空でも tool_use を伴うアシスタントターンには、空テキストの `assistant_message` イベントを発行する
- render: 本文が空の `assistant_message` は見出し (`## 🤖 Assistant (HH:MM)`) のみ描画する
- テンプレート側での次イベント先読みは採らない。イベント列そのものを正しくすることで md / html が同時に直り、テストも書きやすい

### 注意点

- 同一ターン内で複数の assistant レコード (テキスト → ツール → テキスト) が続く場合に、見出しが重複して増えないこと。イベント発行の単位は従来どおりとし、「テキストも tool_use 由来の見出しもないターン」だけが新規に見出しを持つ

## 項目3 — 複数行 Bash コマンドの全文表示

### 問題

ツール呼び出しの Summary を `firstLine` で描画しているため、heredoc などの複数行コマンドが1行目で切れ、本文が読めない。

### 設計

- render: Summary が複数行の場合はコードフェンスで全文表示、1行なら現状どおりインライン表示
- 複数行判定はテンプレート関数 (例: `isMultiline`) として追加する
- Bash に限定せず、複数行 Summary を持つツール全般に適用する
- html は `<summary>` 内のため視覚上は CSS で1行にクランプし、コピー対象 (copy-src) を全文とする。md のフェンス全文表示と見え方が異なるのは意図的 (折りたたみ UI では1行表示が自然で、全文は展開した input / コピーで取得できる)

## 項目4 — ヘッダー統計へのモデル名追加

### 問題

どのモデルで実行されたセッションかをヘッダーから確認できない。観測ログとの突合ではモデル名が必須項目になる。

### 設計

- parse: assistant レコードの `message.model` を収集し、Session に登場順・重複なしの `Models []string` を追加する
- render: ヘッダー統計の並びに「モデル: claude-fable-5」のように列挙する (複数あればカンマ区切り)
- サブエージェント内部のモデルはメインループのレコードに現れないため、自然にメインループのモデルのみが対象になる
- `message.model` を持たないレコード (user レコード等) は単に無視する。モデルが1つも取れないセッションではモデル行を出さない

## 項目5 — プロジェクトルート配下の絶対パスの相対化

### 問題

ヘッダーでプロジェクトルートを宣言しているにもかかわらず、各ツール呼び出しの Summary が絶対パスのままで行が長い。AI が読む用途ではトークンの無駄にもなる。

### 設計

- parse: ツール Summary を組み立てる箇所で、`ProjectPath` 配下の絶対パスを相対パスに短縮する
- ルート外のパス (`~/.claude/...`、`/tmp/...` など) はそのまま残す
- 対象はパスを Summary に採用するツール (Read / Edit / Write 等)。Bash のコマンド文字列は書き換えない (コマンドの再現性を優先する)
- Summary 生成の一箇所に閉じることで md / html の両方に同時に効かせる

## テスト方針

- 各項目に parse / render のユニットテストを追加する
- golden.md / golden.html を再生成し、差分をレビューする
- E2E fixture に「テキストなしツールターン」「複数行 Bash コマンド」を追加する

## 対象外 (YAGNI)

- ターンごとのモデル名表示 (ヘッダー列挙で足りる)
- Bash コマンド内の絶対パス短縮
